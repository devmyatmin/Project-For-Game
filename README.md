# Clean Godot Project

A minimal Godot 4 project snapshot containing its project settings, main scene, GDScript gameplay files, and application icon.

## Open
Open `project.godot` in Godot 4.5 or newer.

## Excluded from this clean branch
Unity/decompiled source collections, Unity AssetRipper exports, Unity metadata, export presets, and generated Godot cache/build outputs. The original `main` branch remains unchanged.
